# 蔣寶大冒險 - 甘蔗的祝福

彩色鉛筆風的第一人稱速通小遊戲。丟掉甘蔗、發完鮮奶、拆了松山機場，看誰最快。

純前端（Vite + Three.js），沒有後端、沒有圖片或音檔素材：紙張、筆觸、配樂和音效都是程式即時產生的。

## 執行

```
npm install
npm run dev
```

打開終端機顯示的網址。手機和電腦連同一個 Wi-Fi 的話，手機開 `Network` 那個網址就能玩。

## 建置與部署

```
npm run build
```

產出的 `dist/` 是純靜態檔案，任何靜態主機都能放，子路徑也能用。

### 部署（GitHub Pages）

- 網址：https://jiangbao.party/
- push 到 `main` 就會由 `.github/workflows/deploy.yml` 自動 build 並發佈，不用手動上傳 `dist/`
- 自訂網域在 repo 的 Settings → Pages 設定（用 Actions 部署時 GitHub 不看 `CNAME` 檔）
- GitHub Pages 不能自訂回應標頭，CSP、HSTS 等安全標頭由 Cloudflare 的 Response Header Transform Rule 加上。遊戲若要載入新的外部資源（字型、圖片、API），記得同步修改那裡的 CSP

## 操作

- 電腦：點畫面鎖定滑鼠，WASD 移動、滑鼠轉頭、E 互動、1–4 選商店選項、M 地圖、V 切換第一／第三人稱、P 或 Esc 暫停
- 視角也可以在「設定」裡切換；第三人稱看得到蔣寶本人
- 手機：左半邊拖曳移動、右半邊拖曳轉頭，點按鈕互動，點小地圖展開

開場會先播一段約 11 秒的空拍動畫介紹蔣寶，按任意鍵或點一下就能略過；計時在動畫結束後才開始。

## 主線

1. **甘蔗的祝福**：到中山福德宮晚宴拿甘蔗，躲開記者和路人的視線偷偷丟掉，或扛回大安神明桌供起來
2. **生生喝鮮奶**：到金滑國小鮮奶車搬鮮奶發給學生，每人每週限一瓶，可以花錢加碼
3. **拆掉松山機場**：機庫要電鋸、航廈和塔台要怪手，小心起飛的飛機

## 調整

- 遊戲名稱、難度、價格、血量、掉落等所有數值：`src/game/config.js`
- 彩色鉛筆效果（筆觸、紙張露白、輪廓線、陰影色調、抖動頻率）：`src/render/pencil.js`
- 地圖配置與據點位置：`src/world/map.js`

排行榜和成就存在瀏覽器的 localStorage，只記錄在同一台裝置上。

網址加上 `?cam=x,z,朝向,仰角` 可以跳過標題直接出生在指定位置，方便截圖或除錯。
